html-anything 绿色版（Windows x64）
====================================

【启动】双击 start.vbs（推荐，全程无黑窗）或 start.bat。
  - 首次启动会拉起本地服务并自动打开浏览器（默认地址 http://127.0.0.1:3000，被占用时自动换端口）。
  - 服务在后台运行；重复双击不会重复启动，只会再开一个浏览器页。

【停止】双击 stop-server.bat。

【前提】本机已安装并登录编程 Agent CLI（如 claude / codex 等），
应用顶栏会自动检测。检测不到时可在 设置 → Custom path 手动指定路径。

【说明】
  - app/    为 Next.js 应用（请勿改动）
  - runtime/ 内置 Node.js 运行时，无需单独安装 Node
  - run/    运行日志（launch.log）与进程信息，可随时删除
  - 完全本地运行，不出网（模板市场等在线功能除外）

【升级】删掉整个文件夹换新版即可；用户数据存在浏览器里（IndexedDB），
换文件夹不丢数据，但请继续使用同一个浏览器。
