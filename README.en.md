## What is this

Paste Markdown / CSV / Excel / JSON / SQL on the left, pick a template, hit `Ctrl + Enter` — a coding agent already installed on your machine turns it into a beautifully typeset **single-file HTML** in seconds, ready to export for WeChat Official Accounts, Zhihu, X, Xiaohongshu, or as a PNG image.

This repository is the **desktop packaging** of the open-source [nexu-io/html-anything](https://github.com/nexu-io/html-anything): a zero-install, auto-updating Windows desktop app, with GitHub Actions **syncing upstream daily** and building releases automatically.

## Highlights

### 🖥️ A real desktop app

- Standard installer, or a portable zip that just runs
- **No Node.js to install, no terminal to touch**
- All data stays in your local browser storage — fully local

### 🤖 Auto-detects your agents, zero API keys

![On first launch the app detects installed, logged-in agent CLIs](docs/screenshots/agent-picker.png)

On launch the app scans your machine for installed coding agent CLIs — Claude Code, OpenAI Codex, Gemini CLI, Qwen Coder, Aider, and 20+ more — and **reuses your existing login sessions**. No API keys, ever.

### 🎨 75+ typesetting templates

Magazine articles, decks, posters, Xiaohongshu cards, data reports, tweet cards… synced from upstream as they grow.

### ✨ Real output, from this app

![A magazine-style article generated by Codex through this app](docs/screenshots/generated-article.png)

*This article was generated by Codex through the app — a real run, not a mockup.*

### 🔄 Fully automatic updates

- In-app update checks (on launch + every 6 hours)
- One click → **delta download (seconds) → silent install → auto restart**
- Automatic mirror fallback when GitHub is unreachable — updates work even without a proxy on CN networks
- When upstream updates, GitHub Actions builds and publishes a new release in the cloud; your app picks it up the next day

## Build from source

```bash
git clone https://github.com/Geerdan1995/html-anything-desktop.git
cd html-anything-desktop

# Workspace deps must be installed in hoisted mode
# (the standalone output requires a symlink-free layout)
pnpm install --node-linker=hoisted

# Build the Next.js standalone output + assemble the portable build
pnpm -F @html-anything/next build
node packaging/portable/build-portable.mjs

# Build the Electron installer (output in dist/desktop-out/)
cd packaging/desktop && npm ci
node build-desktop.mjs
```

Day-to-day releases are fully automated by [.github/workflows/desktop-release.yml](.github/workflows/desktop-release.yml): daily upstream check → sync & rebase → build → smoke test → publish.

## Relationship with upstream

Forked from [nexu-io/html-anything](https://github.com/nexu-io/html-anything) (Apache-2.0). Upstream code carries exactly **one changed line** (`next.config.ts`, enabling standalone output); everything else is additive packaging infrastructure, so upstream merges stay conflict-free:

```
├── next/                  # upstream Next.js app (one-line change: next.config.ts)
├── packaging/
│   ├── portable/          # portable build: launcher + assembly script
│   └── desktop/           # Electron shell: main process, loader, builder config
├── docs/screenshots/      # screenshots used by the READMEs
└── .github/workflows/     # daily sync + build + release pipeline
```
